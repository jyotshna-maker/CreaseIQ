# 14. Future Enhancements

1. **Granular ball-by-ball ingestion:** Parsing full ball-by-ball delivery sequences (accessible via Cricsheet's detailed JSON schema) through our extensible `MatchSource` interface. This would unlock live, in-play win probability curves conditioned on current run rate, remaining wickets, and balls remaining, alongside phase-specific bowling and batting metrics (such as death-overs economy and powerplay strike rates).
2. **Individual player rating representations:** Formulating squad-level strength aggregates derived directly from historical individual player metrics and auction valuations. Squad reconstitution during mega-auctions represents the primary reason purely franchise-level historical metrics lose predictive power across tournament cycles.
3. **Regime-aware and time-decayed modeling:** Introducing explicit temporal decay factors into model training sets, incorporating era-specific parameters, or implementing Bayesian hierarchical models that model team-by-season random effects while preserving strict walk-forward validation protocols.
4. **Meteorological and pitch telemetry:** Incorporating local atmospheric data (such as evening relative humidity to gauge dew presence), pitch condition evaluations, and ground-specific boundary dimensions to control for known physical confounders in toss and chasing outcomes.
5. **Automated drift remediation:** Establishing automated retraining triggers when the Population Stability Index (PSI) exceeds established warning thresholds, paired with champion-challenger canary deployments before updating active production models.
6. **Decoupled API service interface:** Wrapping our domain services layer with a high-performance RESTful API (such as FastAPI), incorporating rate limiting, API token authentication, and asynchronous prediction handling for multi-client consumption.
7. **Cloud containerization and deployment:** Packaging the application into lightweight OCI container images for deployment to cloud hosting environments (such as Streamlit Community Cloud paired with managed PostgreSQL storage), leveraging our pre-existing database URL abstraction.
8. **Automated ingestion schedulers:** Deploying scheduled pipeline jobs to automatically fetch and validate newly completed tournament scorecards during live tournament seasons, applying our strict validation and dry-run ingestion contracts.
9. **Universal athlete entity resolution:** Migrating player representations from raw scorecard name strings to standardized Cricsheet unique person identifiers, eliminating naming ambiguities across domestic and international rosters.
10. **Comprehensive accessibility auditing:** Conducting thorough keyboard navigation and screen-reader usability audits across the web dashboard, providing high-contrast color palettes and accessible text summaries for all generated charts.
