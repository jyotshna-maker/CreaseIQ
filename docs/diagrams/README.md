# Diagrams

The sources are Mermaid (`*.mmd`). Render them with `python scripts/render_diagrams.py` (mermaid-cli 12, Node ≥ 22.13) to SVG and a PNG at 3× scale.

| ID | Diagram | File |
|---|---|---|
| D1 | System architecture | `D1_architecture.png` |
| D2 | Data pipeline / process flow | `D2_data_pipeline.png` |
| D3 | User workflow (activity) | `D3_user_workflow.png` |
| D4 | Use case (actors, FR IDs) | `D4_use_case.png` |
| D5 | Sequence: serving a prediction | `D5_sequence_predict.png` |
| D6 | Sequence: training and evaluation | `D6_sequence_train.png` |
| D7 | Class diagram | `D7_class.png` |
| D8 | Component / package diagram (the allowed imports) | `D8_components.png` |
| D9 | ER diagram (from `db/models.py`; DDL in `../schema.sql`) | `D9_er.png` |
| D10 | Deployment / environment | `D10_deployment.png` |
| D11 | Walk-forward timeline (generated by matplotlib) | `../../reports/figures/walk_forward_timeline.png` |
| D12 | Model lifecycle state diagram | `D12_model_lifecycle.png` |

Mermaid has no native use-case notation. D4 uses circles for actors and stadium shapes for use cases inside a system boundary, with «include» relations drawn as dotted arrows.
